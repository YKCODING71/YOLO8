05 ESP32 통신 설정

Wi-Fi(IP) 또는 USB 시리얼(COM)을 선택하세요. YOLO ID 0 = LED ON, ID 1 = LED OFF.

ESP32 웹서버의 /on, /off 경로로 명령을 전송합니다.

ESP32 USB 케이블을 연결하고 아래의 '포트 연결'을 눌러 목록에서 COM 포트를 선택하세요. Chrome/Edge PC에서 HTTPS 또는 localhost로 접속해야 합니다. Arduino 시리얼 모니터는 닫아 주세요.
